# Archive

Planning papers and logs from the early phases of the project. They are kept for the record and are **not** maintained: the current state is in `README.md`, `STATUS.md` and `docs/IMPROVEMENT_LOG.md`.

| File | What it was |
|---|---|
| `CONTEXT.md`, `NEW CONTEXT.md` | The shared brief for the four-person split (streams A to D) and the frozen contracts (stage record, output line). The contracts still hold; they are restated in the README. |
| `LOOP.md`, `LOOP-A.md` to `LOOP-D.md` | The task loops for each stream: A (real NeMo Curator install and comparisons), B (regulatory filters), C (PII), D (dashboard). Their files refer to each other by name, which is why they sit together. |
| `nemocurator-project-blueprint.pdf` | The original project blueprint. |
| `quality_comparison_log.txt` | Raw log of the DeBERTa quality-classifier comparison (the write-up is `docs/A1_4_quality_classifier_comparison.md`). |
| `logs/nemo_curator_install.log`, `logs/spacy_model_dl.log` | The failed native-Windows install of NeMo Curator and a spaCy model download (see `SETUP.md`). |
